# Adivio Infotech website

A responsive one-page IT company website built with plain HTML, CSS and JavaScript. Includes Adivio Infotech logo artwork and the supplied office address.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Before publishing
- Replace `hello@adivioinfotech.com` in `script.js` with your real business email.
- Update the company description and services if your actual offerings differ.
- Add your real phone number, office address and social links if you want them displayed.
- Connect the contact form to a backend or form service if you want enquiries stored online. The current form opens the visitor's email app.

## Deploy
Upload `index.html`, `style.css` and `script.js` to any static host such as Netlify, Vercel or GitHub Pages.
